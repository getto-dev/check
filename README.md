# Smeta — профессиональный PWA-калькулятор смет

**Smeta** — автономное веб-приложение (PWA) для составления, расчёта и выгрузки смет прямо на объекте. Архитектура приложения не привязана к одной профессии: каталог и настройки загружаются как отдельные профили данных.

**🔗 Ссылка на проект:** [https://getto-dev.github.io/check/](https://getto-dev.github.io/check/)

---

**⚡ Ключевые возможности и функционал**

**1. Профили и каталоги**

- **Профиль «Сантехника»:** основной каталог из 271 позиции, разбитый на 12 категорий.
- **Профиль «Электрика»:** тестовый каталог для проверки архитектуры многопрофильного приложения; его цены не являются коммерческим прайс-листом.
- **Отдельный репозиторий данных:** каталоги живут независимо от кода приложения и могут обновляться без изменения интерфейса.
- **Кэширование профилей:** после первой загрузки выбранный каталог сохраняется локально и доступен офлайн.

**2. Расчёт сметы**

- **Автоматический подсчёт:** мгновенный перерасчёт общей стоимости при изменении количества и состава сметы.
- **Кастомные позиции:** можно вручную добавить работу или материал, которых нет в каталоге.
- **Скидка:** расчёт итоговой суммы с учётом скидки клиента.

**3. PWA и автономность**

- **Offline-first:** приложение продолжает работать с уже загруженными данными без подключения к интернету.
- **Установка на устройство:** Smeta устанавливается на смартфон, планшет или ПК как отдельное приложение.

**4. Хранение и экспорт**

- **Экспорт в PDF:** формирование документа, готового для печати или отправки клиенту.
- **Сохранение сметы:** проект можно сохранить локальным HTML-файлом.
- **Импорт сметы:** ранее сохранённый файл можно загрузить обратно для редактирования.
- **Совместимость:** Smeta продолжает импортировать сметы, созданные старой версией приложения под прежним названием.

---

### Репозиторий данных

Каталоги профилей находятся в отдельном репозитории:

`https://github.com/getto-dev/check-data`

Приложение получает список профилей из `index.json`, затем загружает manifest и файлы выбранного профиля. Перед сохранением в локальный кэш данные проходят структурную валидацию.

### Сборка

```bash
NEXT_PUBLIC_BASE_PATH=/check bun run build
```
