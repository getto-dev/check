СантехСчёт
PWA-калькулятор для расчёта смет на сантехнические работы.

👉 https://getto-dev.github.io/check/

Возможности
📋 200+ услуг в 12 категориях
💰 Автоматический расчёт сметы
💸 Учёт скидок
📄 Экспорт в PDF для печати
✏️ Ручное добавление позиций
💾 Сохранение и открытие смет в файл — смета сохраняется локально на устройство в виде HTML-файла и открывается обратно для редактирования
📱 Устанавливается как приложение (PWA)
🔌 Работает офлайн
```bash
NEXT_PUBLIC_BASE_PATH=/checknew bun run build
```
